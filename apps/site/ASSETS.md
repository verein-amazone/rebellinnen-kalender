# Website assets: where each file comes from

Every image the website ships, with its source and the basis for using it. Update this list when an
asset is added or replaced. It lives here rather than inside `public/assets/`, because the build
copies that folder to the published site as is. Paths are relative to `public/`.

Also shipped, but made elsewhere: `favicon.ico` and `apple-touch-icon.png` are written by
`apps/app/scripts/generate-app-icons.mjs` from the default app icon; the share image is the Play
feature graphic (`apps/app/fastlane/metadata/android/de-DE/images/featureGraphic.png`), which the
build emits under `_astro/`; and the fonts come from `@amazone/design-system`, published with their
OFL licence texts under `fonts/`.
