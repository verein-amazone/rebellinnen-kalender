# Website assets: where each file comes from

Every image the website ships, with its source and the basis for using it. Update this list when an
asset is added or replaced. It lives next to `site/assets/` rather than inside it, because the build
copies that folder to the published site as is.

| File                                     | Source                                                                                                                                                                                  | Basis for use                                                                                                                                                                                                             |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `assets/icon.webp`                       | `resources/app-icons/cool-cat-nacht.png`, resized to 256 px with `cwebp -q 85` (16 October 2026)                                                                                        | The app's default icon, supplied by Verein Amazone (see `docs/app-icon.md`).                                                                                                                                              |
| `assets/screens/heute.webp`              | `fastlane/screenshots/de-DE/01-heute.png`, `cwebp -q 82 -resize 600 0`                                                                                                                  | The app's own screen. Shows the portrait of Clara Zetkin, public domain (`public/content/images.json`, id `clara-josephine-zetkin`).                                                                                      |
| `assets/screens/kalender.webp`           | `fastlane/screenshots/de-DE/02-kalender.png`, same conversion                                                                                                                           | The app's own screen with invented demo appointments.                                                                                                                                                                     |
| `assets/screens/rebellin.webp`           | `fastlane/screenshots/de-DE/03-rebellin.png`, same conversion                                                                                                                           | The app's own screen. Shows the portrait of Ada Lovelace by Alfred Edward Chalon, public domain (`public/content/images.json`, id `ada-lovelace`).                                                                        |
| `assets/screens/anlaufstellen.webp`      | `fastlane/screenshots/de-DE/06-anlaufstellen.png`, same conversion                                                                                                                      | The app's own screen, the same image as the store screenshot. The emoji are the system emoji font of the machine that rendered the screenshot.                                                                            |

Only 203 × 88 px, so it is slightly soft on high-density screens. **To ask the Hil-Foundation** for a vector or larger file and whether this is the logo to use. |

Also shipped, but generated from elsewhere at build time: `favicon.ico` from `public/`,
